# 꿈의 탈출 (Dream Escape)

등불 하나 메고 어두운 꿈에 들어가, **99초 안에 출구를 찾아 살아 나오면** 그동안 주운 금화와 룬이 내 것이 된다. 죽거나 시간이 다 되면 전부 잃는다.

웹 브라우저용 익스트랙션 어드벤처 · HTML 파일 하나 · 설치 없음

**▶ 플레이: https://duros221.github.io/dream-escape/**

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 이동 / 터치 | 커서 쪽으로 이동 |
| F / R | 조우 시 맞서 싸운다 / 도망친다 |
| 전투 중 몬스터 반대쪽 3번 클릭 | 도망친다 (체력 -2) |
| Enter | 로비에서 시작 · 결과 화면에서 로비로 |

## 규칙 요약

- 한 화면(box) 30m×30m, 전체 지도(map)는 box 9개. 탈출구는 매 판 랜덤, 희미한 푸른 빛.
- 등불은 3m에서 시작해 10초마다 0.5m 넓어진다. 몬스터는 등불 반경의 1.5배에서 당신을 알아챈다.
- 몬스터 15종. 겉모습으로 힘을 알 수 없다 — 65%는 약하고, 10%는 한 방에 죽인다.
- 처치·보물상자 → 금화 1~10, 갑옷/무기, 20% 확률로 룬. box마다 절반 확률로 부활의 샘.
- 로비에서 같은 룬 3개를 합치면 능력이 영구히 1단위 오른다. 룬 판매 5🪙, 100🪙로 3개 구매.
